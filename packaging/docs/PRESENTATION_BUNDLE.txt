===============================================================
   ORIENTAL INSTRUMENT BY DJBILBOX BEATS
   BUNDLE VST3 COMPLET
===============================================================

Plonge ta production dans les sonorités du Moyen-Orient et
d'Afrique du Nord. Conçu par DJBILBOX BEATS (Toulouse), développé
en C++ / JUCE — taillé pour le Hip-Hop, l'Afrotrap, le Deep House,
l'Oriental et l'Arabic.

---------------------------------------------------------------
FEATURES TECHNIQUES
---------------------------------------------------------------
  - Polyphonie : 32 voix simultanées
  - Latence : < 5 ms (buffer 128 samples)
  - RAM : ~180 MB chargé en mémoire
  - Moteur : multisample + accordage maqam micro-tonal
  - FX intégrés (8) : Reverb, Echo, Chorus, Distort,
    Compressor, EQ, Phaser, Bitcrush
  - Molettes : Pitch-Bend + Vibrato (MOD) expressifs
  - Compatible : VST3 — Windows 10/11 & macOS 12+
  - Intégration native FL Studio (wrapper VST3 testé)

---------------------------------------------------------------
SONS & PACKS INCLUS
---------------------------------------------------------------
  - 895 samples — vrais instruments orientaux
  - 280 presets (40+ signature production-ready)
  - Qanun acoustique (multi-vélocité, plusieurs octaves)
  - Oud acoustique & électro (fingerpicked & strummed)
  - Violin / Rababah orientaux (legato & staccato)
  - Naï (Ney) & Mizmar (legato & staccato)
  - Percussions : Darbuka
  - Synthés orientaux : pads arabesque, leads maqam

---------------------------------------------------------------
POURQUOI LES BEATMAKERS L'ADOPTENT
---------------------------------------------------------------
  - Sons uniques introuvables dans les packs génériques
  - Workflow rapide — drag & drop, MIDI-ready
  - Presets organisés par genre (Trap, Deep, Arabic Club)
  - Zéro latence perceptible en sessions intensives
  - UI pro : arabesque dorée + monument Maqam Echahid (Alger)

---------------------------------------------------------------
  Windows : lance le .exe, accepte la licence, entre le mot de
