BLOCKER: JAVA/ANDROID TOOLCHAIN
===============================================================================

The following are NOT installed and must be installed before building:

  X Java Development Kit (JDK) 11+
  X Android SDK (API 21, 34)
  X Android NDK 26.0.10792818
  X Gradle 8.1+ (or gradle wrapper will download)
  X CMake 3.22.1+

Check Prerequisites:
  $ java -version
  $ ls $ANDROID_SDK_ROOT/platforms/android-34
  $ ls $ANDROID_NDK_HOME/toolchains/llvm
  $ cmake --version

Setup Instructions:
  1. Install Java JDK 11 or higher
  2. Install Android SDK (via Android Studio SDK Manager)
  3. Install Android NDK 26.0.10792818
  4. Install CMake 3.22.1+
  5. Copy android/local.properties.template -> android/local.properties
  6. Edit local.properties with your SDK/NDK paths
  7. Run: cd android && ./gradlew assembleDebug
